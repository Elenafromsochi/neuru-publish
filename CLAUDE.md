# CLAUDE.md — neuru-email

## Репозитории сессии

При каждом старте сессии обязательно выполни:

```
add_repo Elenafromsochi/neuru-publish
```

Это нужно для того чтобы ИИ-агенты могли читать данные из `neuru-publish` (новости, интервью, стратегии) и записывать результаты своей работы обратно в этот репозиторий.

Без выполнения этой команды push в `neuru-publish` завершится ошибкой доступа.

---

## Структура проекта

### neuru-email (основной репо)
Система email-рассылок НЭЙРУ. Содержит:
- `/research/` — дайджесты новостей (ИИ-Новостник)
- `/strategy/` — планы рассылок (ИИ-Стратег рассылок)
- `/copy/` — тексты писем (ИИ-Копирайтер рассылок)
- `/analytics/` — аналитика рассылок (ИИ-Аналитик)
- `/base/` — база правил, каналы, тон, подпись

### neuru-publish (дополнительный репо)
Система публикаций НЭЙРУ для социальных сетей. Содержит:
- `/social-news/` — новости отобранные для публикаций (по неделям)
- `/social/strategy/` — стратегии публикационных кампаний (ИИ-Стратег-Публицист)
- `/social/interviews/` — результаты интервью с отельерами (ИИ-Интервьюер)
- `/social/copy/` — готовые тексты публикаций (ИИ-Копирайтер-Публицист)

## Правила для всех агентов

- Коммить напрямую в `main` — без веток и pull request
- Не выдумывать цифры — только из прочитанных файлов
- Не останавливаться из-за мелких пробелов — фиксировать в ВОПРОСЫ и продолжать
- Имена файлов определять по дате запуска
